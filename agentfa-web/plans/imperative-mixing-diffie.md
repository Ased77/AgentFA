# پلن ساخت: پلتفرم فروشگاه و چت ایجنت‌های هوش مصنوعی فارسی

## Context

کاربر می‌خواهد یک پلتفرم فارسی (RTL، دارک‌مود، قیمت‌گذاری تومانی) بسازد که در آن کاربران عادی ثبت‌نام می‌کنند، توکن هدیه می‌گیرند، در فروشگاهی از ایجنت‌های تخصصی هوش مصنوعی جستجو می‌کنند، آن‌ها را می‌خرند و با آن‌ها چت می‌کنند. هر پیام چت بر اساس مصرف Claude API توکن مصرف می‌کند.

اسپک اصلی (`src/imports/deepseek_markdown_20260909_952432.md`) برای **Next.js 14 + Supabase** نوشته شده، اما پروژه‌ی واقعی یک **Vite + React 19 SPA** با اسکافولد خالی است (فقط react/react-dom نصب است، بدون بکاند). این پلن اسپک را با استک واقعی تطبیق می‌دهد.

**تصمیمات کاربر:**
- بکاند: **Supabase واقعی + Claude API واقعی** (نه دیتای ساختگی).
- دامنه‌ی مرحله‌ی اول: **هسته‌ی اصلی** — لندینگ، احراز هویت، فروشگاه، چت، داشبورد. (ادمین، دعوت دوستان، پرومو‌کد، اشتراک/قیمت‌گذاری پیشرفته به فاز بعد موکول می‌شوند.)

**خروجی مورد نظر:** یک MVP قابل استفاده و باکیفیت با احراز هویت واقعی، دیتابیس، خرید شبیه‌سازی‌شده، و چت استریم واقعی با Claude که موجودی توکن را کم می‌کند.

## پیش‌نیازها (اولین گام‌های اجرا)

1. **اتصال Supabase:** با ابزار `supabase_connect` مودال اتصال را نمایش بده. تا زمانی که کاربر متصل نشده، کد بکاند نوشته نشود. یادآوری کن که Make برای جمع‌آوری اطلاعات حساس/PID مناسب نیست.
2. **ذخیره‌ی کلید Claude:** با ابزار `create_supabase_secret` و نام `ANTHROPIC_API_KEY` کاربر کلید را امن ذخیره کند. این کلید فقط در Edge Function استفاده می‌شود، هرگز در فرانت.
3. **جهت‌گیری زیبایی‌شناسی:** قبل از نوشتن UI، اسکیل `aesthetic-stance` فراخوانی و سپس `create_make_theme` با یک توضیح ۱–۲ جمله‌ای (پلتفرم فارسی RTL دارک‌مود مینیمال بنفش/آبی برای فروشگاه ایجنت‌های AI) صدا زده شود. توکن‌های اسپک (رنگ‌ها، شعاع‌ها) به‌عنوان مبنا استفاده شوند.

## استک و کتابخانه‌های موردنیاز (نصب در ابتدای اجرا)

- `react-router-dom` — مسیریابی چندصفحه‌ای (اسکیل `react-router` قبل از افزودن مسیریابی بارگذاری شود).
- `@supabase/supabase-js` — کلاینت Supabase (فایل‌های `utils/supabase/info.tsx` پس از اتصال خودکار ساخته می‌شوند).
- `recharts` — نمودار مصرف توکن در داشبورد.
- آیکون‌ها: از یک ست سبک (مثلاً `lucide-react`) استفاده شود؛ ایجنت‌ها از ایموجی اسپک استفاده می‌کنند.

## بکاند (Supabase)

**جداول (مرحله‌ی اول) — طبق بخش ۵ اسپک، همه timestamptz پیش‌فرض now():**
- `users` (extends auth.users): id, email unique, full_name, avatar_url?, provider default 'email', token_balance default 50000, monthly_token_limit default 50000, plan default 'free' (free/basic/pro), is_admin default false, created_at, updated_at.
- `agents`: id, name, slug unique, description, long_description, features jsonb, icon, category, price int (تومان), system_prompt, model, temperature float default 0.3, max_tokens int default 4096, suggested_prompts jsonb, welcome_message, rating float default 4.5, total_sales int default 0, is_active default true, is_featured default false, created_at, updated_at.
- `conversations`: id, user_id (cascade), agent_id, title default 'گفتگوی جدید', total_tokens default 0, created_at, updated_at.
- `messages`: id, conversation_id (cascade), role (user/assistant/system), content, tokens default 0, model?, created_at.
- `token_usage`: id, user_id, agent_id, conversation_id, message_id?, prompt_tokens, completion_tokens, total_tokens, cost_usd numeric(10,6)?, created_at.
- `transactions`: id, user_id, type (topup/subscription/purchase/refund/referral_bonus), amount int (تومان، مثبت=اعتبار)، tokens_added int, status (pending/success/failed), payment_method default 'zarinpal' (یا 'mock'), payment_ref?, created_at.
- `purchased_agents`: id, user_id, agent_id, purchased_at — یکتا روی (user_id, agent_id).

**جداول فاز بعد:** `subscriptions`، `promo_codes`، `referrals`، `rate_limits` (طبق تعاریف بخش ۵). ایندکس روی کلیدهای خارجی و ستون‌های پرکاربرد (user_id, agent_id, created_at).

- RLS فعال: هر کاربر فقط ردیف‌های خودش را می‌بیند؛ `agents` عمومی‌خواندنی.
- تریگر `on auth.users insert` → ساخت ردیف `users` با ۵۰,۰۰۰ توکن هدیه.
- Seed: ۶ ایجنت از بخش ۷ اسپک (فارسی کامل: name, slug, icon, category, price, rating, total_sales, description, long_description, features, system_prompt, model, temperature, max_tokens, suggested_prompts, welcome_message).

**Edge Function `/chat`:**
1. احراز کاربر با JWT.
2. بارگذاری agent + conversation + ۱۰ پیام آخر.
3. ساخت آرایه‌ی پیام‌ها: system_prompt + تاریخچه + پیام جدید.
4. فراخوانی Claude API با استریم (`agent.model`؛ مدل‌های اسپک منسوخ‌اند — از **مدل‌های فعلی Claude** استفاده شود: پیش‌فرض `claude-sonnet-5`، و برای ایجنت ارزان `claude-haiku-4-5-20251001`. مقادیر model در seed به این‌ها نگاشت شوند). قبل از فراخوانی، اسکیل `claude-api` برای پارامترها/فرمت استریم بارگذاری شود.
5. استریم پاسخ به کلاینت (SSE/ReadableStream).
6. پس از پایان: ثبت `token_usage`، کم‌کردن `token_balance`، افزایش `conversations.total_tokens`، ذخیره‌ی پیام‌ها.
7. اگر موجودی ناکافی → خطای ۴۰۲ با پیام فارسی؛ خطای Claude → ۵۰۰ با «خطا در ارتباط با هوش مصنوعی»؛ تایم‌اوت → «پاسخی دریافت نشد، لطفاً دوباره تلاش کنید.».

**منطق مدیریت توکن (بخش ۶.۱):**
- ثبت‌نام: token_balance=50000، monthly_token_limit=50000، مودال خوش‌آمد.
- قبل از هر فراخوانی: تخمین توکن موردنیاز (طول system_prompt + ۱۰ پیام آخر + max_tokens)؛ اگر balance < تخمین یا مصرف ماهانه+تخمین > سقف ماهانه → بلاک و پرامپت خرید.
- بعد از پاسخ: کم‌کردن total_tokens از balance، درج token_usage، افزایش conversations.total_tokens، محاسبه‌ی مصرف ماهانه از token_usage ماه جاری.
- هشدار موجودی کم: بنر در چت زیر ۲۰٪ سقف، هشدار پررنگ‌تر زیر ۱۰٪، بلاک+مودال در صفر.
- top-up توکن: انتخاب بسته → transaction با status='success' → افزودن توکن (شبیه‌سازی MVP).
- rate limit (۲۰/دقیقه، ۱۰۰/ساعت، ۵۰۰/روز) و ریست ماهانه‌ی توکن → **فاز بعد** (نیازمند جدول rate_limits و cron).

**مدل‌ها:** مقادیر model در seed اسپک (`claude-3-5-sonnet`/`claude-3-5-haiku`) منسوخ‌اند و به مدل‌های فعلی نگاشت می‌شوند: sonnet → `claude-sonnet-5`، haiku → `claude-haiku-4-5-20251001`. temperature/max_tokens هر ایجنت طبق seed حفظ شود.

## منطق فرانت‌اند (هسته) — نگاشت دقیق بخش ۴ اسپک

### لندینگ `/` (۴.۱)
- **هدر:** لوگوی متنی «ایجنت‌فا»؛ لینک‌های ناوبری فروشگاه/قیمت‌ها/ورود؛ CTA «شروع رایگان» → signup. اگر کاربر لاگین است، آواتار + لینک داشبورد.
- **Hero:** عنوان «دستیارهای هوش مصنوعی که واقعاً کارهات رو انجام می‌دن»؛ زیرعنوان اسپک؛ دکمه‌ی اصلی «شروع رایگان – ۵۰,۰۰۰ توکن هدیه» و دکمه‌ی ثانویه «مشاهده دمو»؛ پس‌زمینه‌ی گرادیان ملایم.
- **ایجنت‌های منتخب:** گرید ۶ ایجنت پرطرفدار (کارت: آیکون، نام، امتیاز، قیمت، توضیح کوتاه، دکمه‌ی «مشاهده») + لینک به فروشگاه.
- **چطور کار می‌کند:** سه مرحله با آیکون — ثبت‌نام / انتخاب ایجنت / چت و نتیجه.
- **نظرات کاربران:** ۳ testimonial فارسی نمونه (آواتار، نام، نقل‌قول).
- **سوالات متداول:** آکاردئون با ۶ سوال اسپک (ایجنت چیست، هزینه، دانش فنی، خرید توکن، لغو اشتراک، ضمانت بازگشت وجه).
- **فوتر:** لینک‌های قوانین و مقررات/حریم خصوصی/تماس با ما + کپی‌رایت.

### احراز هویت (۴.۲)
- **Signup `/signup`:** فرم نام کامل/ایمیل/رمز/تکرار رمز؛ دکمه «ثبت‌نام»؛ «ورود با گوگل»؛ در موفقیت ریدایرکت به داشبورد + مودال «۵۰,۰۰۰ توکن هدیه به حساب شما اضافه شد!». پشتیبانی از پارامتر `?ref=` برای دعوت (فاز بعد).
- **Login `/login`:** فرم ایمیل/رمز؛ دکمه «ورود»؛ لینک «فراموشی رمز عبور؟»؛ Google OAuth.
- **Verify `/verify`** و **Reset `/reset-password`:** طبق قالب‌های Supabase Auth؛ پیام‌های فارسی اسپک و دکمه‌ی ارسال مجدد.
- محافظت از مسیرها: کاربر ناشناس → ورود با returnUrl.

### فروشگاه `/marketplace` (۴.۳)
- نوار جستجوی زنده در بالا.
- تب دسته‌ها: همه/توسعه/داده/مارکتینگ/کسب‌وکار/طراحی.
- dropdown مرتب‌سازی: محبوب‌ترین/جدیدترین/ارزان‌ترین/گران‌ترین.
- گرید کارت (۳ ستون دسکتاپ، ۱ موبایل): آیکون بزرگ، نام، توضیح یک‌خطی، ستاره‌های امتیاز (⭐ ۴.۸)، تعداد فروش («۱,۲۳۴ فروش»)، قیمت تومانی.
- دکمه‌ها بر اساس وضعیت: ناشناس → مشاهده/خرید (خرید→ورود)؛ لاگین و نخریده → خرید؛ خریده → چت + مشاهده.
- بج «پرفروش» اگر is_featured، «جدید» اگر ظرف ۳۰ روز اخیر ساخته شده.
- حالت خالی: «هیچ ایجینتی مطابق جستجو یافت نشد.»

### جزئیات ایجنت `/agent/:slug` (۴.۴)
- بخش بالا: آیکون بزرگ، نام، امتیاز، تعداد فروش، قیمت؛ دکمه‌ها (نخریده → «خرید ایجنت» + «پیش‌نمایش رایگان» با ۳ پیام محدود؛ خریده → «شروع چت»)؛ بج «ضمانت ۷ روزه بازگشت وجه».
- توضیحات (long_description)؛ لیست features؛ چیپ‌های suggested_prompts (کلیک → شروع چت با آن پرامپت)؛ ۲–۳ ریویوی استاتیک با نام فارسی؛ تا ۴ ایجنت مرتبط از همان دسته.

### خرید ایجنت (شبیه‌سازی MVP — بخش ۶.۳)
- مودال تأیید با قیمت و موجودی؛ ثبت `transactions` (type='purchase', status='success', payment_method='mock')، درج در `purchased_agents`، افزایش `total_sales`. کامنت که Zarinpal واقعی جایگزین می‌شود؛ کد باید حالت شکست را هم بپذیرد.

### چت `/chat/:agentId` (۴.۵)
- **سایدبار راست (۲۸۰px):** لیست گفتگوهای همین ایجنت؛ دکمه‌ی «گفتگوی جدید»؛ هر آیتم: آیکون، عنوان، پیش‌نمایش آخرین پیام، زمان، تعداد توکن؛ حالت خالی «گفتگویی ندارید».
- **مرکز:** هدر (آیکون، نام، نشانگر «آنلاین»، دکمه‌های «دانلود گفتگو» و «پاک‌کردن گفتگو»)؛ ناحیه‌ی پیام‌ها (کاربر راست‌چین پس‌زمینه‌ی primary، ایجنت چپ‌چین پس‌زمینه‌ی card با بوردر؛ زیر پیام ایجنت «مصرف: N توکن»؛ اندیکاتور تایپ سه‌نقطه؛ گفتگوی جدید → welcome_message + چیپ‌ها)؛ ورودی textarea با auto-resize، آیکون پیوست (غیرفعال)، دکمه‌ی ارسال؛ Enter ارسال، Shift+Enter خط جدید.
- **سایدبار چپ (۲۵۰px، جمع‌شونده):** اطلاعات ایجنت (آیکون/نام/دسته)؛ «مصرف این گفتگو»؛ «موجودی توکن شما» زنده؛ دکمه‌ی «خرید توکن بیشتر» → مودال بسته‌ها؛ «ارتقا پلن» → قیمت‌گذاری؛ «پاک‌کردن گفتگو» با تأیید.
- **موبایل:** سایدبارها در همبرگر جمع؛ چت تمام‌عرض.
- **استریم:** `fetch` + `ReadableStream`، افزودن توکن‌ها هنگام دریافت؛ در پایان به‌روزرسانی موجودی.
- **موجودی ناکافی:** مودال «اعتبار توکن شما کافی نیست» با «خرید توکن» و «ارتقا پلن».
- **افزودنی‌ها (بخش ۸):** دانلود ترنسکریپت به‌صورت .txt با پیام‌ها و زمان‌ها؛ تشخیص بلاک کد با regex ``` و دکمه‌ی کپی.

### داشبورد `/dashboard` (۴.۶)
- سایدبار راست: نمای کلی/گفتگوها/ایجنت‌های من/صورتحساب/تنظیمات/دعوت دوستان (تنظیمات و دعوت در فاز بعد).
- **نمای کلی:** «سلام، [name]!»؛ سه کارت آمار (موجودی توکن، ایجنت‌های من، مکالمات این ماه)؛ نمودار خطی Recharts مصرف ۳۰ روز اخیر با لیبل RTL؛ گرید ایجنت‌های من (دکمه‌ی چت)؛ ۵ گفتگوی اخیر با لینک ادامه؛ دکمه‌های «خرید توکن» و «ارتقا پلن».
- **گفتگوها:** همه‌ی گفتگوها با فیلتر ایجنت (dropdown)، جستجوی عنوان؛ هر ردیف: آیکون، عنوان، آخرین پیام، تاریخ، توکن، اقدامات (ادامه/حذف)؛ pagination یا infinite scroll.
- **ایجنت‌های من:** گرید ایجنت‌های خریداری‌شده با دکمه‌ی چت و لینک مشاهده.
- **صورتحساب:** پلن فعلی و موجودی؛ جدول تاریخچه‌ی تراکنش‌ها (تاریخ، توضیح، مبلغ تومان، توکن افزوده، وضعیت)؛ بسته‌های توکن که خرید را شبیه‌سازی می‌کنند (بخش ۶.۱: ثبت transaction با status='success' و افزودن توکن).

## افزودنی‌ها و لبه‌ها (بخش‌های ۸ و ۹)

**افزودنی‌ها:** دانلود ترنسکریپت .txt؛ دکمه‌ی کپی برای بلاک کد؛ ایمیل تأیید از قالب Supabase Auth (ایمیل‌های موجودی کم/تأیید خرید → لاگ/نوتیف درون‌برنامه‌ای به‌عنوان placeholder، Resend در فاز بعد)؛ دارک‌مود دائمی بدون toggle؛ متا‌تگ SEO با `lang="fa"` و عنوان/توضیح هر مسیر (در SPA با به‌روزرسانی `document.title`)؛ lazy-load کامپوننت‌های سنگین.

**لبه‌ها/خطاها:** کاربر ناشناس → ورود با returnUrl؛ ایجنت یافت‌نشد → صفحه‌ی ۴۰۴؛ گفتگوی حذف‌شده → ریدایرکت به گفتگوی جدید؛ تایم‌اوت API → «پاسخی دریافت نشد...»؛ rate limited → پیام فارسی با زمان تلاش مجدد (فاز بعد)؛ موجودی ناکافی → مودال؛ شکست پرداخت (mock) → همیشه موفق ولی کد آماده‌ی حالت شکست.

**نکات پروژه (`AGENTS.md`):** پرهیز از `*{margin:0}` بدون لایه؛ فونت‌ها در `src/index.css` (`@import` اول)؛ export پیش‌فرض کامپوننت‌ها؛ کوتیشن دوتایی برای رشته‌های دارای آپاستروف؛ بدون فایل config برای Tailwind v4.
