# Custom (non-Claude) AI provider — token/time paid access, agents only

Implementation note for `agentfa-web`. The desktop companion (Tauri,
`agency-agents-app`) implements the same contract — see that repo's
`memory-bank/decisions.md` and `contracts.md`.

## What this adds

- `src/lib/provider.ts` — the admin-owned provider profile (localStorage
  `agentfa-provider`): base URL, model, API key, meter, rates, agent scope.
- `src/lib/provider-client.ts` — streaming OpenAI-compatible client
  (`POST {baseUrl}/chat/completions`, `stream: true`), usage capture via
  `stream_options.include_usage`, idle timeout, abort, closed error taxonomy.
- `src/lib/mock-store.ts` — wallet v2: token **and** time allowances with
  in-place migration from the v1 tokens-only shape; agent ownership
  (`ownsAgent` / `ownAgent` / `ownedAgents`) moved here from `routes.tsx`.
- `src/pages/Chat.tsx` — real streamed replies (demo reply only when no
  provider is configured), ownership + scope gating, cancellation.
- `src/pages/Admin.tsx` — provider section with a connection test.
- `src/data/personas.generated.ts` — agent persona bodies (generated by
  `scripts/generate-catalog.mjs`, capped at 2400 chars), imported lazily by the
  chat page only.

## Contract shared with the desktop app

```jsonc
{ "version": 1, "id": "custom-1", "label": "", "baseUrl": "https://…/v1",
  "model": "…", "meter": "tokens" | "time",
  "rate": { "tomanPer1kTokens": 2000, "tomanPerMinute": 30000 },
  "agentScope": ["*"], "enabled": true }
```
Meter semantics: pre-check reserves a minimum (the character estimate, or one
minute), then the debit is trued-up after the stream — provider-reported tokens
when available, otherwise the estimate; time is always measured wall-clock, in
seconds, displayed in minutes.

## "Agents only" — three independent guards

1. There is no provider path outside an agent conversation.
2. `Chat` refuses before spending when the agent isn't owned or isn't in the
   profile's `agentScope`.
3. Every request carries the agent persona as the system message; the
   connection test uses a probe persona and never debits a wallet.

## How to try it locally

1. Open `/admin` with the admin flag set (the existing gate):
   `localStorage.setItem("agentfa-is-admin", "true")` in the console, then reload.
2. In **AI provider**, fill base URL (`https://api.deepseek.com/v1`, or a local
   Ollama at `http://localhost:11434/v1`), model, and API key, then press
   **Test connection**. Offline / browser-origin-hostile endpoints: tick
   *Route through the dev proxy* and start Vite with
   `PROVIDER_PROXY_TARGET=https://…` (see `vite.config.ts`).
3. Buy an agent from its detail page (simulated checkout) → **Chat** now streams
   real replies and debits the meter the profile selected.
4. Flip the meter to `time` and send a message: the wallet spends seconds and
   the sidebar shows minutes.

## Known limitations (deliberate, MVP)

- The API key sits in localStorage and is readable by any script on the origin.
  Admin-only configuration + masking is the mitigation; a backend proxy is the
  real fix and is the natural next step.
- Payments stay simulated (`topUp`, `choosePlan`); plans grant both meters,
  bundles are token-only — the time meter refills via plans.
- Enforcement is client-side: a user with devtools can bypass the meters. That
  is inherent to a backend-less SPA.
- Providers that ignore `stream_options.include_usage` are billed on the
  estimate; the UI doesn't distinguish beyond the reported/estimated flag on the
  outcome.
